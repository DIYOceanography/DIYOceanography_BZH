Feedback & contributor Guides
=============================

Contributing to the website
----------------------------
Did you notice missing or erroneous information? DIY Oceanography BZH is meant to be a community platform and we welcome feedback and contributions you just need to fork on our `GitHub repository <https://github.com/DIYOceanography/DIYOceanography_BZH>`_ and follow the README instructions.

Alternatively you may open an issue in the `github issues page <https://github.com/DIYOceanography/DIYOceanography_BZH/issues>`_.

Current need for contributions :
---------------------------------

We are currently looking for contributions in the following areas:

 - **Passive acoustics**
 - **Sea level**
 - **Underwater positioning**
 - **PAR**

Ultimately we aim to cover : data loggers, biofouling, physical containering and mechanical design of the hosting platform, electronics, github projects and good practices for open source projects.


Contribution to the Zotero library is also welcome, join the `DIY Oceanography BZH Zotero group <https://www.zotero.org/groups/6090995/diy_oceanography_bzh>`_.
